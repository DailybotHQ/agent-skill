# Brand assets

Both logos are the official Dailybot horizontal logo, downloaded from
`www.dailybot.com/images/brand/`, with a **transparent background**.

| File | Source | Use |
|---|---|---|
| `logo-dark.svg` | `logo-horizontal-white.svg` | White ink — dark backgrounds. The README serves this one on GitHub's dark theme. |
| `logo-light.svg` | `logo-horizontal-black.svg` | Black ink — light backgrounds. The README serves this one on GitHub's light theme, and as the fallback for renderers without theme switching. |

These files are repository infrastructure: they are not part of the shipped
`skills/dailybot/` artifact.
